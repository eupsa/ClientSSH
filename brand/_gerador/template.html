ClientSSH

Identidade visual do cliente SSH open source para Windows, só em azul-escuro, preto e branco. O símbolo é um "C" aberto com o prompt >_ dentro: o cliente e o shell numa forma só, com a saída do anel apontando para o servidor.

$ ssh usuario@servidor ▍

Logo

Arquivos SVG em logo/ e PNGs em png/. O símbolo puro usa grade 24×24 com traço de 2px. Em 16–32 px use a versão "small" do tile, com traço mais grosso.

Assinaturas com nome

Cores e tipografia

Clique numa cor para copiar o hex. Só azul-escuro, preto e branco. Nome em Inter SemiBold + Bold (OFL), já convertido em curvas nos SVGs.

Animações

20 animações em Lottie JSON (60 fps, 240×240) na pasta anim/, cobrindo os estados de uma sessão SSH. Cada uma tem versão para tema claro e .dark.json para tema escuro. Clique no palco para pausar.

Ícones do app

Pasta msix/ pronta para substituir Assets/ do projeto WinUI empacotado. Escalas 100–400% e targetsizes 16–256 (com altform-unplated e lightunplated).
